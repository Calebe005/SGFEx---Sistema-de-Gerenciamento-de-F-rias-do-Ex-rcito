# SGFEx---Sistema-de-Gerenciamento-de-F-rias-do-Ex-rcito
Sistema web para gestão de férias de militares. Permite cadastro de férias por militar/subunidade, dashboard com quantitativos por posto/graduação e mês, gerenciamento com status de publicação, e relatório diário de militares que entram de férias, ordenados por posto e graduação.
